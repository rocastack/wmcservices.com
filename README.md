**WMC Services** es una plataforma corporativa y una landing page de alta fidelidad diseñada para modernizar el vínculo entre empresas y clientes. Especializados en BPO (Business Process Outsourcing) y gestión de centros de contacto, combinamos infraestructura de vanguardia con talento humano especializado para transformar los contactos comerciales en motores de crecimiento escalables.

---

## 💼 Servicios Estratégicos

El núcleo de nuestras operaciones consta de 4 pilares fundamentales para el ecosistema corporativo:

*   **📞 1. Contact Center Omnicanal**
    *   **Enfoque:** Unificamos todas las vías de comunicación (voz, chat, email y redes sociales) bajo una sola interfaz operativa.
    *   **Beneficio:** Aseguramos una trazabilidad absoluta de las interacciones y una respuesta coherente, elevando los estándares de la experiencia del cliente (CX).

*   **📊 2. Gestión Integral (Call Center)**
    *   **Enfoque:** Potenciamos la operación con tecnología de vanguardia para gestionar el ciclo de vida completo del cliente.
    *   **Beneficio:** Manejo experto de embudos de ventas, seguimiento posventa, cobranzas, resolución de quejas y tickets de soporte.

*   **🎯 3. Estrategia Activa (Telemarketing)**
    *   **Enfoque:** Maximizamos el alcance con campañas síncronas enfocadas en la promoción directa de productos y cierre de ventas.
    *   **Beneficio:** Captura de feedback directo y cualitativo en tiempo real para refinar y mejorar continuamente la oferta de valor.

*   **🌐 4. Operativa Continua 24/7**
    *   **Enfoque:** Maximizamos la conversión con negociadores y analistas expertos disponibles las 24 horas del día, los 7 días de la semana.
    *   **Beneficio:** Ausencia total de fricción horaria para el cliente final, garantizando el máximo retorno por cada centavo de inversión corporativa.

## ⚡ Experiencia de Usuario Premium (UI/UX)

*   **Animaciones y Microinteracciones Fluidas:** Todo el sitio web respira vida mediante un motor de físicas de animación (`Framer Motion`). Desde el revelado al hacer scroll, hasta contadores numéricos acelerados por hardware.
*   **Internacionalización (i18n) Dinámica:** Soporte robusto y nativo para conmutación de idiomas en tiempo real (Inglés y Español) mediante una arquitectura de estado global reactivo.
*   **Diseño Neumórfico y Glassmorphism:** Incorporación de desenfoques profundos, brillos ambientales y una estructura bento-grid que otorga un aire hiper-tecnológico y corporativo.
*   **Sistema de Backend Serverless:** Integración perfecta con funciones ocultas en la nube (`Netlify Functions` + `Nodemailer`) para captar formularios de empleo y captación comercial, renderizando las respuestas en correos HTML hermosos para el equipo de ventas.

## 🛠️ Stack Tecnológico

El proyecto está construido bajo una arquitectura moderna orientada a la altísima conversión y rendimiento visual:

*   **Vite + React:** Bundling ultrarrápido y renderizado ágil de componentes e interfaces modulares.
*   **Framer Motion:** Animaciones fluidas, transiciones de diseño y detección de intersecciones en el scroll.
*   **Lucide React:** Sistema iconográfico consistente, minimalista y de peso ultraligero.
*   **Netlify Forms & Functions:** Backend-as-a-Service para la captura de leads, inyección de variables de entorno (Nodemailer SMTP) y protección contra bots.
*   **CSS Vanilla Avanzado:** Sistema de estilos sin dependencias, utilizando `clamp()` para tipografías fluidas, variables CSS dinámicas y Flexbox/Grid moderno.
